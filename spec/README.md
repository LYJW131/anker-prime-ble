# Cross-language contract

Generated by `tools/contract.py`. **Do not edit anything here by hand** — the
Python modules in `anker_prime_ble/` are the source of truth, because they carry
the evidence for every field in their comments. These files are a projection of
them for implementations that cannot import Python.

```bash
python3 tools/contract.py export   # regenerate
python3 tools/contract.py verify   # fail if stale — wire this into CI
```

## `protocol.json` and `AnkerPrimeSpec.swift`

The constants: GATT UUIDs, crypto material, command and TLV numbers, the
charger's cable and vendor tables, the power bank's port-block offsets.

Constants are the easy half of staying in sync. Get one wrong and the device
refuses to connect, or a table lookup misses — loud, immediate failures.

## `fixtures/` — the part that matters

For each capture in `captures/`, the decoded state after every frame.

This exists because the failures that actually hurt are not wrong constants but
wrong *interpretations*: a second implementation that reads a byte differently
produces plausible numbers forever and nobody notices. This repository hit that
five times in one afternoon — see [NOTES.md](../NOTES.md) — and every one of
them looked right at the time.

So the contract is behavioural. Any other implementation replays a capture's
frames through its own decoder and must reproduce these states field for field:

```
for each frame in fixture.frames:
    feed capture bytes for frame.command into the decoder
    assert decoder.state == frame.state
```

A fixture pins down more than a field map can state: that an idle port reports
its power slot as stale rather than zero, that `0xA4` tracks temperature and not
power flow, that the dock block freezes instead of resetting. Those are the
things a reimplementation gets wrong.

## Adding a capture

Record it, replay it, eyeball that the decode is right, then `export`. The new
fixture becomes part of the contract from then on.

If a decoder change alters an existing fixture, that is the point of this
directory: read the diff and decide whether the old output or the new one is
correct. A fixture changing silently in a commit that claimed to be a refactor
is exactly what this catches.
